# 🛠️ System Toolkit & Encoder

Многофункциональная CLI-утилита на Python, объединяющая инструменты для системного администрирования (блокировка сайтов), мониторинга (вывод информации о системе) и работы с данными (декодер HEX, Base64 и двоичного кода).

## ✨ Возможности

- **🔒 Блокировка сайтов:** Быстрое добавление и удаление доменов в системном файле `hosts` для ограничения доступа.
- **📊 Информация о системе:** Вывод ключевых параметров ОС, процессора, оперативной памяти и сетевых интерфейсов.
- **🔠 Универсальный декодер:** Перевод строк и файлов из форматов **HEX**, **Base64** и **Binary (двоичный код)** в читаемый текст.

## 🚀 Требования и установка

### Требования

- Python 3.13 или выше
- Права администратора / root (требуются _только_ для функции блокировки сайтов, так как она модифицирует системный файл `hosts`).

### Установка

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Platin-Time/vsparcer-new.git
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
